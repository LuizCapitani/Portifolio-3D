## Sobre

Este repositório reúne **personagens, assets e cenários 3D** criados no **Blender**, além de **jogos e experiências interativas** desenvolvidas no **Roblox Studio**. O foco é unir **modelagem, ambientação e lógica de jogo** em projetos coesos, com atenção a proporção, iluminação e usabilidade dentro da engine.
